# Bookflix

Bookflix is a mobile-first prototype for personalized book discovery.

## Current MVP

- Search public book metadata via Open Library
- Select books you loved
- Build a lightweight reader profile
- Generate a short set of explained recommendations
- Responsive dark streaming-style interface

## Product direction

> Give us 3 books you loved. We'll find what you should read next.

The next product stages are authentication, persistent library, ratings, a stronger recommendation engine, AI explanations, surprise mode, and premium features.
