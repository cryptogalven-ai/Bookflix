Confidentialité

Bookflix est actuellement un prototype sans compte utilisateur.

Données locales

Les livres sélectionnés, notes, bibliothèque, historique et préférences apprises peuvent être conservés dans le stockage local de ton navigateur. Ces données restent sur ton appareil tant que tu ne les effaces pas.

Export et import

Bookflix permet d'exporter ton profil dans un fichier JSON et de le réimporter sur un autre appareil. Le fichier est créé localement et n'est pas envoyé automatiquement à Bookflix.

Partage

La fonction de partage utilise le mécanisme de partage de ton appareil lorsqu'il est disponible. Sinon, Bookflix peut copier le texte des recommandations dans le presse-papiers.

Recherche de livres

Les recherches sont envoyées à Open Library afin de récupérer les informations publiques sur les livres et leurs couvertures.

Pas de profil serveur

Bookflix ne crée actuellement pas de compte et ne centralise pas ton historique de lecture sur un serveur Bookflix.
